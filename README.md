# Live Webcams — Support

Official bilingual support site for Live Webcams, by Casaxmore.

- Website: https://casaxmore.github.io/livewebcams-support/
- Contact: casaxmore@gmail.com
- English by default. Direct Spanish link: `?lang=es`; English: `?lang=en`.
- `index.html`: native FAQs, email support template and first-layer support privacy notice.
- `privacy.html`: bilingual support-website privacy notice, also saved as `PRIVACY_NOTICE.en/es.md`.
- `app-privacy.html`: separate English app privacy policy, matching the canonical LiveWebcams project policy dated November 23, 2026. This is also saved as `APP_PRIVACY_POLICY.en.md`. Existing Drive/App Store URLs are not automatically changed by publishing this site.
- No analytics, cookies, local storage, external fonts, embedded videos or external scripts. Contact opens the mail app; no message is sent automatically.
- Preserve `icono.jpg` and `app-ads.txt`.

Preview with `python3 -m http.server 8080`. GitHub Pages serves the root of the master branch; verify the deployment after pushing.

Source model: the Silence Dog support site was used as the requested layout and contact-privacy reference; copy and FAQ answers are specific to Live Webcams. Follow the notice’s retention and rights commitments when handling support messages.
